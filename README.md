# Jersey_Wooly_Breeder_Evals
Evaluation of Jersey Wooly Rabbit Breeders within the Norwestern Region.
The evaluation is based off of data from https://www.njwrcsweeps.com/ which is the official records from the National Jersey Wooly Rabbit Club. Points are awarded to exhibitors based firstly off the amount of animals in a class and secondly the placement of the animal within the class. 

This dataset does not have information on the breakdown of the points awarded per exhibitor nor does it have any information on any breeder not registered with the National Jersey Wooly Rabbit Club. To reduce the first issue, this analysis focuses on points per show which balances out any exhibitor who shows in a lot of shows, but does not get many points per show. However, this does not filter for breeders who show very well, but only have a couple of animals.
